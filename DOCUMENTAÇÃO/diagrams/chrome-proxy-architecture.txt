Container can't connect to Chrome?
│
├─► Run: verify-chrome-setup.bat
│   │
│   ├─► ❌ Config invalid?
│   │   └─► Fix config.json
│   │       └─► Set BROWSER_MODE="wsEndpoint"
│   │       └─► Set DEBUG_PORT="http://192.168.0.2:9224"
│   │       └─► Set CHROME_PROXY_ENABLED=true
│   │
│   └─► ✅ Config valid
│       └─► Continue below
│
├─► Run: start-chrome-proxy.bat
│   │
│   ├─► ❌ Chrome won't start?
│   │   ├─► Check if port 9224 occupied: netstat -ano | findstr :9224
│   │   ├─► Kill existing Chrome: taskkill /IM chrome.exe /F
│   │   └─► Retry
│   │
│   ├─► ❌ Proxy won't start?
│   │   ├─► Check if port 9224 occupied: netstat -ano | findstr :9224
│   │   ├─► Kill process: taskkill /PID <PID> /F
│   │   ├─► Check proxy script exists: dir scripts\chrome-proxy-service.js
│   │   └─► Test manually: node scripts\chrome-proxy-service.js 192.168.0.2 debug
│   │
│   └─► ✅ Both started
│       └─► Continue below
│
├─► From container, test: curl http://192.168.0.2:9224/json/version
│   │
│   ├─► ❌ Connection refused?
│   │   ├─► Check Windows Firewall
│   │   │   └─► netsh advfirewall firewall add rule name="Chrome Proxy 9224" dir=in action=allow protocol=TCP localport=9224
│   │   ├─► Check IP is correct
│   │   │   └─► ipconfig (Windows) → Get actual IPv4
│   │   └─► Retry
│   │
│   ├─► ❌ Response has ws://localhost:9224 (not rewritten)?
│   │   ├─► Proxy not rewriting URLs correctly
│   │   ├─► Check proxy logs in "Chrome Proxy Service" window
│   │   └─► Restart proxy with correct PUBLIC_IP
│   │
│   └─► ✅ Response has ws://192.168.0.2:9224/devtools/browser/...
│       └─► Perfect! Proxy working correctly
│
