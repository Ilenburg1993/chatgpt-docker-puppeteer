# INTEGRACOES

**Propósito**: concentrar a referência de integrações estáveis e playbooks técnicos ligados a ferramentas externas.  
**Status documental**: Canônico.  
**Público**: engenharia, integração e agentes de IA.  
**Última atualização**: 28 de fevereiro de 2026.

## O que esta pasta contém

- documentação de integração entre o runtime e ecossistemas externos;
- playbooks técnicos de fluxos compostos;
- material de referência para interoperabilidade recorrente.

## Entradas principais

- [RAG_MCP_LSP_PLAYBOOK_PTBR.md](./RAG_MCP_LSP_PLAYBOOK_PTBR.md)

## O que não deve ficar aqui

- guias gerais de onboarding;
- arquitetura principal do projeto;
- relatórios históricos de integração encerrada.

## Regras de manutenção

- Se a integração for um contrato ou playbook estável, ela pode viver aqui.
- Se o conteúdo passar a ser apenas plano ou experimento temporário, ele deve migrar para `PLANOS/`
  ou `ARQUIVO_MORTO/`.
- O foco desta pasta é interoperabilidade técnica, não operação diária.
