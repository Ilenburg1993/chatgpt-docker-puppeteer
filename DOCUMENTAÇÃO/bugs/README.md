# Alias de Documentacao de Bugs

Esta pasta existe para compatibilidade com o caminho solicitado (`DOCUMENTAÇÃO/bugs`).

## Politica Anti-Fragmentacao

- Fonte canonica: `DOCUMENTAÇÃO/BUGS/`
- Nao manter conteudo divergente entre `BUGS` e `bugs`.
- Todo conteudo operativo deve ser atualizado primeiro no canonico.

## Arquivos de Referencia

- Tracker vivo: `DOCUMENTAÇÃO/BUGS/CODEX_AUDIT_TRACKER.md`
- Master historico: `DOCUMENTAÇÃO/BUGS/BUG_AUDIT_MASTER.md`
