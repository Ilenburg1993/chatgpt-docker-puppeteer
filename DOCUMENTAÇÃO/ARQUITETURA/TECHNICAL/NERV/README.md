# NERV

**Propósito**: concentrar análises técnicas intermediárias específicas do barramento NERV, ainda não
promovidas ao baseline.  
**Status documental**: Canônico de apoio.  
**Público**: engenharia, manutenção e agentes de IA.  
**Última atualização**: 28 de fevereiro de 2026.

## O que esta pasta contém

- análises técnicas localizadas do ecossistema NERV;
- investigações de envelope, contrato e comportamento do barramento;
- material útil para evolução técnica ainda não promovido ao hub principal.

## Entradas principais

- [ANALISE_NERV_ENVELOPE.md](./ANALISE_NERV_ENVELOPE.md)

## O que não deve ficar aqui

- documentação canônica principal do NERV;
- material histórico já superseded;
- notas genéricas de arquitetura sem foco no barramento.

## Regras de manutenção

- Se uma análise aqui virar conhecimento estável, ela deve ser promovida para `SUBSISTEMAS/NERV.md`
  ou para outro documento canônico de arquitetura.
- Se perder utilidade e virar apenas histórico, deve migrar para `ARQUIVO_MORTO/`.
