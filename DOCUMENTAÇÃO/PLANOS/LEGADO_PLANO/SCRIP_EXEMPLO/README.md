# SCRIP_EXEMPLO

**Propósito**: concentrar artefatos e exemplos de código ligados a planos legados, usados como apoio ilustrativo e não como fonte canônica de implementação.  
**Status documental**: Histórico.  
**Público**: engenharia e manutenção.  
**Última atualização**: 28 de fevereiro de 2026.

## O que esta pasta contém

- exemplos de código e arquivos de apoio vinculados a planos antigos;
- protótipos de componentes e contratos exploratórios;
- arquivos de texto usados como referência de comparação.

## O que não deve ser assumido

- nada aqui deve ser tratado como implementação oficial atual;
- nada aqui substitui os módulos vivos em `src/`;
- esses arquivos são anexos de contexto, não baseline.

## Exemplos presentes

- variações de driver, factory, constants e validation;
- exemplos de UI (`.vue`);
- arquivos de tarefa e schemas experimentais.

## Regras de manutenção

- Se algum artefato daqui voltar a ser útil como código vivo, ele deve ser reavaliado e promovido a
  um local canônico adequado.
- Fora isso, esta pasta deve permanecer apenas como apoio histórico.
