## Achados

### BUG-20260215-001
- Severidade: `P0`
- Status: `patch-proposto`
- Tipo: `bug`
- Arquivo principal: `src/main.js:708`
- Evidencia objetiva:
  - Em `Promise.race`, o primeiro item e uma funcao `async () => { ... }` e nao uma Promise executada.
  - Trecho: `await Promise.race([ async () => { ... }, new Promise(...) ])`
- Impacto tecnico e risco:
  - Inicializacao SSOT pode ser "ignorada" pelo race.
  - Sistema pode aparentar boot concluido sem workers SSOT efetivamente inicializados.
- Causa-raiz:
  - Erro de contrato de `Promise.race`: recebeu funcao em vez de invocacao.
- Proposta de correcao (patch sugerido, nao aplicado):
```diff
diff --git a/src/main.js b/src/main.js
@@
-            await Promise.race([
-                // Inicialização normal
-                async () => {
+            await Promise.race([
+                // Inicializacao normal
+                (async () => {
@@
-                },
+                })(),
```
- Estrategia de teste:
  - Criar `tests/unit/main/test_boot_ssot_init.spec.js` validando que inicializacao SSOT realmente executa antes de resolver o race.
  - Cobrir timeout com fake timers para garantir rejeicao quando init real nao conclui.
- Dependencias e risco de regressao:
  - Dependente do contrato atual de boot SSOT em `src/main.js`.
  - Baixo risco externo; alto ganho de confiabilidade no boot.
- Historico:
  - `2026-02-15`: confirmado e marcado como patch-proposto.

```diff
     await new Promise((resolve, reject) => {
@@

+    // Handshake explicito do protocolo Maestro

+        identity: {
+            robot_id: `maestro-${process.pid}`,
+            instance_id: process.env.NODE_APP_INSTANCE || String(process.pid),
+            version: PROTOCOL_VERSION,
+        },
+    };
+
```

```diff
@@

+import dotenv from 'dotenv';
+
+if (fs.existsSync('.env.local')) {
+  dotenv.config({ path: '.env.local', override: true });
+}
+dotenv.config();
+
+await import('../main.js');
```
```diff
diff --git a/package.json b/package.json
@@
-    "start": "node index.js",
+    "start": "node src/entry/maestro_entry.js",
```
