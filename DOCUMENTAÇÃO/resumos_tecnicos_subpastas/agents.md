# agents

Resumo técnico:
A pasta agents contém implementações de agentes autônomos, prompts e configurações específicas para agentes (por exemplo, "Primeiro Agente - GPT-5-MINI.prompt.yml"). Provê definição de comportamento, orquestra prompts e integra com o kernel/NERV para executar tarefas automatizadas.

Arquivos típicos:
- Prompts YAML, perfis de agentes, adaptadores para drivers.

Uso e responsabilidades:
- Definir fluxos de conversação e estratégia de execução de tarefas.
