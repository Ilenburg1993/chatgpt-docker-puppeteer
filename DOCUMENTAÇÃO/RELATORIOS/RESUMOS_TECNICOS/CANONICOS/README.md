# Resumos Técnicos das Subpastas do Código

Esta pasta contém resumos técnicos detalhados sobre a função de cada subpasta presente no diretório
`src` do projeto. Cada arquivo descreve o propósito, principais responsabilidades e integração de
cada módulo ou componente.

Consulte os arquivos individuais para entender o papel de cada subpasta na arquitetura do agente.
