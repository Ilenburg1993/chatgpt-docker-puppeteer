# rodadas

**Propósito**: registrar rodadas históricas de auditoria e varredura de bugs quando essa trilha
precisar voltar a armazenar snapshots nomeados.  
**Status documental**: Canônico de apoio.  
**Público**: engenharia, auditoria e agentes de IA.  
**Última atualização**: 28 de fevereiro de 2026.

## Estado atual

Neste momento, esta pasta está essencialmente vazia e mantida apenas para sustentar a estrutura da
taxonomia de auditorias.

O placeholder atual existe para:

- preservar a árvore planejada;
- permitir futuras rodadas sem recriar a pasta;
- manter previsibilidade de caminho.

## O que deve viver aqui

- snapshots nomeados de rodadas de bug audit;
- relatórios de rodada quando fizer sentido separar por ciclo;
- artefatos de acompanhamento diretamente ligados a uma rodada específica.

## O que não deve viver aqui

- o backlog mestre de bugs;
- a trilha principal de auditoria;
- documentos gerais de status.

## Regras de manutenção

- Se a rodada for apenas um detalhe já consolidado no master, não duplique sem necessidade.
- Se a pasta continuar sem conteúdo real, mantenha apenas a estrutura mínima.
