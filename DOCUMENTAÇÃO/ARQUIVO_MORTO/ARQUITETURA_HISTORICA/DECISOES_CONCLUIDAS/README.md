# DECISOES_CONCLUIDAS

**Propósito**: preservar decisões arquiteturais concluídas que hoje têm valor histórico, mas não
comandam mais o baseline vigente.  
**Status documental**: Histórico.  
**Público**: engenharia, arquitetura e auditoria.  
**Última atualização**: 28 de fevereiro de 2026.

## Natureza histórica

Esta subpasta guarda decisões concluídas, changelogs e registros de fechamento ligados a ciclos
arquiteturais anteriores.

## O que não é canônico

- decisões vivas ou novos ADRs devem ir para `DOCUMENTAÇÃO/DECISOES/`;
- esta pasta existe apenas para rastreabilidade de decisões já encerradas.
