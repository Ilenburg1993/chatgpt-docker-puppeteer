# CODE_SUMMARY

**Propósito**: preservar resumos históricos de inventário e leitura estrutural de código.  
**Status documental**: Histórico.  
**Público**: engenharia e auditoria.  
**Última atualização**: 28 de fevereiro de 2026.

## Natureza histórica

Esta subpasta guarda resumos legados de código que foram mantidos por contexto, não como fonte
canônica.

## O que não é canônico

- inventários vivos devem ser reavaliados contra a árvore atual;
- não assumir que estes resumos refletem o estado presente do código.
