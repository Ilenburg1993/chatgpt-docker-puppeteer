# CHECKLISTS_HISTORICOS

**Propósito**: preservar checklists antigos mantidos apenas por consulta histórica e rastreabilidade.  
**Status documental**: Histórico.  
**Público**: engenharia e auditoria.  
**Última atualização**: 28 de fevereiro de 2026.

## Natureza histórica

Este diretório guarda checklists que já não comandam a execução atual, mas ainda podem ser úteis
como referência comparativa.

## O que não é canônico

- checklists ativos devem viver em `PLANOS/` ou em categorias vivas específicas;
- o conteúdo daqui não deve ser usado como fonte primária de trabalho novo.
