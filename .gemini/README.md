# .gemini/

**Propósito**: Configuração e instruções para o assistente Gemini (Google AI) neste repositório —
estilo, instruções de contexto, plano mestre e configuração de integração.  
**Status**: Canônico de apoio.  
**Público**: Assistentes Gemini e desenvolvedores que configuram a integração com Google AI.  
**Última atualização**: 2 de março de 2026.

## O que esta pasta contém

- Arquivos de configuração do Gemini (`config.json`, `config.yaml`)
- Instruções de contexto e estilo (`instructions.md`, `styleguide.md`)
- Plano mestre de tarefas (`PLANO_MESTRE.md`)

## O que não deve ficar aqui

- Segredos, chaves de API ou tokens de acesso
- Artefatos de runtime ou logs gerados pelo assistente

## Entradas principais

| Arquivo           | Descrição                                        |
| ----------------- | ------------------------------------------------ |
| `config.json`     | Configuração principal do Gemini em formato JSON |
| `config.yaml`     | Configuração principal do Gemini em formato YAML |
| `instructions.md` | Instruções de contexto para o assistente Gemini  |
| `styleguide.md`   | Guia de estilo e convenções do projeto           |
| `PLANO_MESTRE.md` | Plano mestre de tarefas e roadmap                |
