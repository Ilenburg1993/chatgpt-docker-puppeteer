# commands — .opencode/

**Propósito**: Comandos customizados disponíveis no assistente OpenCode — ações rápidas para tarefas
frequentes no projeto como verificação de Ollama, busca RAG, triagem de Chrome e validação.  
**Status**: Canônico de apoio.  
**Público**: Assistente OpenCode e desenvolvedores que trabalham com comandos customizados.  
**Última atualização**: 2 de março de 2026.

## O que esta pasta contém

| Arquivo            | Descrição                                        |
| ------------------ | ------------------------------------------------ |
| `ollama-check.md`  | Comando para verificar status do servidor Ollama |
| `rag-search.md`    | Comando para busca semântica via RAG             |
| `triage-chrome.md` | Comando para triagem de problemas com Chrome     |
| `validate.md`      | Comando para validação geral do ambiente         |
