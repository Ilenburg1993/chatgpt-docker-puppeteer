## 3. Análise de Dependências Inter-Métodos

### Paths Críticos
1. **start()** → agentStart → (cria session, wira eventos)
2. **startDialogLoop()** → dialogStart → (inicia DialogLoopManager)
3. **sendMessage()** → msgSend → (enfileira turno)
4. **sendDialogTurn()** → dispatchAgentDialogTurn → (dialog-specific)

### Métodos Chamados Internamente
- `#processQueue()` é chamado por `EMITTER_PROCESS_QUEUE`
- `#tryReconnect()` é delegado por `#processQueue`
- `ensureDialogLoopAttached()` usado em init

### Getters com Lógica Não-Trivial
- `toolsRegistry` → `getToolRegistrySnapshot()`
- Todas as sombras de pergunta → `readRuntimeInteractionState()`

## 10. Atualização ONDA 2 — barrel-first operacional concluída (2026-05-13)

Antes de continuar a extração de métodos de `AlwaysAliveAgent`, a retomada validou a ONDA 2 já iniciada por outra LLM
e fechou o gate estrutural de imports/exports no padrão 2.0/2.1 usado em `terminal/` e `presentation/`.

### Entregas aplicadas nesta retomada

- `npm run typecheck:strict:src.copilot` foi executado primeiro, conforme solicitado, e expôs barrels auto-referenciais
  introduzidos na migração parcial:
  - `agent/error/index.js`;
  - `agent/runtime/contracts/index.js`;
  - `agent/event-bridge/index.js`.
- Os barrels foram corrigidos para apontarem para os owners reais:
  - `error-policy.js`;
  - `runtime-contracts.js`;
  - `event-bridge-wiring.js` + `event-bridge-map.js`.
- Imports operacionais cross-folder dentro de `src/copilot/agent/**` foram migrados para barrels/sub-barrels ou
  superfícies públicas:
  - `#copilot/config` e `#copilot/config/agent`;
  - `#copilot/core`;
  - `#copilot/dialog`;
  - `#copilot/bridges`;
  - `#copilot/event-handlers`;
  - `#copilot/observability`;
  - `#copilot/sdk`.
- `#copilot/dialog` foi formalizado no `package.json` e em `tsconfig.base.json`.
- `#copilot/bridges` passou a exportar `createMcpToolBridge`, evitando bypass de `mcp-tool-bridge.js`.
- `#copilot/observability` passou a exportar `buildStatusSnapshot`, evitando bypass de `observability/snapshots.js`.
- `#copilot/config/agent` foi formalizado como sub-barrel público das constantes operacionais de `config/agent.js`,
  sem inflar novamente o root `#copilot/config`.
- Novo contrato:
  - `tests/unit/copilot/contracts/test_agent_barrel_governance.spec.js`.

### Métrica ONDA 2 após correção

Critério usado, alinhado a `terminal`/`presentation`:

- `index.js` pode reexportar leafs, desde que seja barrel puro;
- same-folder privado pode continuar direto;
- arquivos operacionais não-`index.js` não podem cruzar pastas internas de `agent` via leaf import.

Resultado:

- relative module specs em `src/copilot/agent`: **369**;
- via barrel `*/index.js`: **184**;
- leaf total: **185**;
- `crossFolderLeafNonIndex`: **0**;
- `sameFolderLeafNonIndex`: **12**;
- `indexBarrelLeafExports`: **173**.

### Gates executados

- `npm run typecheck:strict:src.copilot`: **verde**.
- `npm run test:copilot:unit`: **2609/2609 verde**.

### Status

**ONDA 2 está 100% concluída para o escopo barrel-first operacional.**

O que permanece não é falha da ONDA 2:

- reexports leaf em `index.js` puros, que são a função dos barrels;
- imports same-folder privados;
- wildcard `#copilot/agent/*` ainda existente como compatibilidade white-box/testes, já documentado como dívida de
  superfície pública para uma fase posterior.

Próximo passo arquitetural correto: prosseguir com C3.2 de decomposição moderada do `AlwaysAliveAgent`, agora sobre uma
base de imports estabilizada e governada.
