# artifacts/prompts/

**Propósito**: Prompts do sistema de auditoria — templates reutilizáveis e versões renderizadas (preenchidas com contexto) geradas durante a execução de tarefas de auditoria.  
**Status**: Artefato de runtime (rendered) / Canônico de apoio (templates).  
**Público**: Sistema de auditoria e desenvolvedores que criam ou revisam prompts de auditoria.  
**Última atualização**: 2 de março de 2026.

## O que esta pasta contém

| Pasta | Descrição |
|---|---|
| `rendered/` | Prompts renderizados (gerados automaticamente — não comitar) |
| `templates/` | Templates de prompts reutilizáveis |
