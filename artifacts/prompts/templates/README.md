# artifacts/prompts/templates/

**Propósito**: Templates de prompts reutilizáveis para o sistema de auditoria — definem a estrutura e o conteúdo base dos prompts que serão renderizados com contexto específico em cada execução.  
**Status**: Canônico de apoio.  
**Público**: Desenvolvedores e agentes de IA que criam ou revisam prompts de auditoria.  
**Última atualização**: 2 de março de 2026.

## O que esta pasta contém

Templates organizados por tarefa de auditoria. Cada subpasta corresponde a um tipo de tarefa.
