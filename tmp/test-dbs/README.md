# tmp/test-dbs/

**Propósito**: Bancos de dados SQLite temporários criados durante a execução dos testes de integração — isolam o estado de teste do banco de produção.  
**Status**: Artefato de runtime.  
**Público**: Sistema de testes (uso interno automático).  
**Última atualização**: 2 de março de 2026.

## ⚠️ Não comitar o conteúdo desta pasta

Os bancos de dados são criados e destruídos automaticamente e **não devem ser commitados**.
